COMANDOS DOCKER - UBBike
========================

Ubicarse en la carpeta del proyecto
-----------------------------------
cd /c/Users/kathe/OneDrive/Desktop/Documento_seba/ubbike/ubbike


Subir el proyecto normalmente
----------------------------
docker compose up -d


Subir el proyecto reconstruyendo imagenes
-----------------------------------------
docker compose up -d --build


Subir el proyecto sin cache
---------------------------
docker compose build --no-cache
docker compose up -d


Ver estado de los contenedores
------------------------------
docker compose ps


Ver logs de todos los servicios
-------------------------------
docker compose logs -f


Ver logs solo del backend
-------------------------
docker compose logs -f backend


Ver logs solo del frontend/mobile
---------------------------------
docker compose logs -f mobile


Ver logs solo de la base de datos
---------------------------------
docker compose logs -f db


Ver logs solo de Redis
----------------------
docker compose logs -f redis


Ver logs solo de Mailpit
------------------------
docker compose logs -f mailpit


Bajar el proyecto sin borrar datos
----------------------------------
docker compose down


Bajar el proyecto borrando volumenes y datos
--------------------------------------------
docker compose down -v


Reiniciar limpio sin borrar datos
---------------------------------
docker compose down
docker compose up -d --build


Reinicio limpio completo sin cache, sin borrar datos
----------------------------------------------------
docker compose down
docker compose build --no-cache
docker compose up -d


Reinicio total borrando base de datos
-------------------------------------
docker compose down -v
docker compose build --no-cache
docker compose up -d


Subir solo servicios de apoyo para desarrollo local
---------------------------------------------------
docker compose up -d db redis mailpit


Detener solo un servicio
------------------------
docker compose stop backend
docker compose stop mobile
docker compose stop db
docker compose stop redis
docker compose stop mailpit


Iniciar solo un servicio detenido
---------------------------------
docker compose start backend
docker compose start mobile
docker compose start db
docker compose start redis
docker compose start mailpit


Reconstruir solo backend
------------------------
docker compose build backend
docker compose up -d backend


Reconstruir solo frontend/mobile
--------------------------------
docker compose build mobile
docker compose up -d mobile


Reconstruir solo backend sin cache
----------------------------------
docker compose build --no-cache backend
docker compose up -d backend


Reconstruir solo frontend/mobile sin cache
------------------------------------------
docker compose build --no-cache mobile
docker compose up -d mobile


Entrar al contenedor backend
----------------------------
docker compose exec backend sh


Entrar a PostgreSQL
-------------------
docker compose exec db psql -U ubbike -d ubbike


Probar Redis
------------
docker compose exec redis redis-cli ping


Ver uso de recursos
-------------------
docker stats


Eliminar imagenes no usadas
---------------------------
docker image prune


Eliminar recursos no usados
---------------------------
docker system prune


Produccion: subir sin cache
---------------------------
docker compose -f docker-compose.prod.yml build --no-cache
docker compose -f docker-compose.prod.yml up -d


Produccion: ver estado
----------------------
docker compose -f docker-compose.prod.yml ps


Produccion: ver logs
--------------------
docker compose -f docker-compose.prod.yml logs -f


Produccion: bajar sin borrar datos
----------------------------------
docker compose -f docker-compose.prod.yml down


Produccion: bajar borrando volumenes y datos
--------------------------------------------
docker compose -f docker-compose.prod.yml down -v
